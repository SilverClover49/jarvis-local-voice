How Jarvis works

A picture guide. No prior knowledge assumed.

1What is this thing?

In one sentence: three programs run on your laptop. One listens, one thinks, one talks. A web page connects them.

That's the whole project. Everything below is detail.

👂

🗣️

You speak. The ears turn your voice into text. The brain reads it and writes a reply. The voice reads the reply aloud. Total: about 1.2 seconds.

Why this is unusual

All three files live on your laptop. Nothing is sent to the internet. Turn off your wifi and it still works. No account, no API key, no monthly bill.

2Setting it up

  1. Install PythonVersion 3.9 or newer. Check with python --version. On macOS or Linux it might be python3.
  2. Run setuppython setup.py — downloads about 700 MB. Takes a few minutes. If it fails, run it again; it skips what it already has.
  3. Start itpython start.py — starts three background processes and opens the page.
  4. Check the dotsTop-right of the page. All three must be green: brain, voice, ear.
  5. Stop itPress Ctrl+C in the window running start.py.

On a Mac or Linux machine

Setup can't download the KoboldCpp and whisper.cpp binaries automatically — they're built per platform. Setup prints the exact link and the exact file location. Download, drop it in bin/, then:

chmod +x bin/koboldcpp bin/whisper-server

Without the ear you can still type; you just can't speak.

3The four pieces

a. The brain

One file, 533 MB, qwen3.5-0.8b-q4_k_m.gguf. That file is the intelligence. Copy it to a USB stick and you've copied the AI.

How can a file "think"?

It can't, exactly. It holds 800 million numbers. You give it text, the numbers do a huge amount of arithmetic, and out comes a guess at what word should come next. Repeat forty times and you have a sentence.

b. The ears

ggml-tiny.en-q5_1.bin, 32 MB, called Whisper. Turns sound into text.

Why not the browser's built-in speech recognition? Because Chrome sends your audio to Google to transcribe it. That would make the whole "private and offline" promise a lie. So we use a local one.

c. The voice

en_GB-alba-medium.onnx, 63 MB, called Piper. Turns text into speech. Four voices ship with it.

This one needs Python

Piper only comes as a Python package, so voice-server.py exists to wrap it in a web address. It's the only Python in the running system, and you never need to edit it.

d. The page

app/index.html + style.css + app.js. This is the bit you see and talk to. It does no AI itself — it just calls the three programs above.

The controls, in plain English

ControlWhat it actually does
TemperatureHow adventurous the word-picking is. 0 = always the likeliest word, so it repeats itself. 0.4 = balanced. 1.2 = creative and frequently wrong.
Reply lengthThe maximum number of tokens (word pieces) before it stops. 40 is roughly one line.
RememberHow many past messages get re-sent each time. This is the entire memory system. 0 means it forgets everything instantly.
PersonaThe system prompt. One sentence telling a generic model who to be.

5Local vs cloud

Flip Where does it think? to Cloud API, paste a Groq key, press Save. The model list fills in from the API. Pick one. Ask the same question again.

This laptop
533 MB
Answers in ~0.4 s. Free forever. Works offline. Private.
Cloud API
70 billion
Smarter. Needs internet. Your words leave the machine. Has a bill eventually.

That comparison is the point of the whole exercise. Neither is better — they're different trades.

6Reading the code

app/app.js is about 1000 lines but only four ideas. Find these and you've read the whole thing. Full walkthrough with line numbers is in docs/CODE-GUIDE.md — this is the short version.

buildPrompt() — the secret handshake

// the model expects text in exactly this shape
<|im_start|>system
You are Jarvis, a warm British butler.
<|im_end|>
<|im_start|>user
Who are you?
<|im_end|>
<|im_start|>assistant
<think>

</think>

Those markers are how the model knows who is speaking.

If you delete the <think> block

The model writes out its entire inner monologue first — "Okay, the user is asking who I am, I should reply as a butler…" — and then reads it aloud. Answers take 7 seconds instead of 0.4.

Always keep the empty, already-closed <think></think>.

askLocal() — talking to the brain

const res = await fetch("http://127.0.0.1:5001/api/v1/generate", {
  method: "POST",
  body: JSON.stringify({ prompt, max_length, temperature }),
});
const data = await res.json();
return data.results[0].text;

127.0.0.1 means "this computer". Not a website. That's why it works offline. And that's the entire AI integration — one HTTP POST.

speak() — talking to the voice

const res = await fetch("http://127.0.0.1:5002/say", {
  body: JSON.stringify({ text, voice, speed }),
});
const bytes = await res.arrayBuffer();  // a WAV file

Same pattern. Ask for something, get bytes, play them.

8Common errors

brain  is red

The model hasn't loaded or crashed.

→ Wait 20 seconds. If still red, read the window running start.py. If it says a file is missing, run python setup.py again.

voice  is red

Piper isn't installed, or the voice server didn't start.

→ pip install piper-tts, then python voice-server.py by hand to see the error.

ear  is red

The whisper binary is missing or won't start. On Windows it needs the .dll files beside it in bin/.

→ Re-run setup, or move the dlls next to the exe. Typing still works without it.

Page is unstyled

A stray comment closer in the CSS has ended the stylesheet early — one bad line kills everything after it, silently.

→ node lint.js finds it.

Cannot set properties of null

The script is looking for an element that doesn't exist — usually a misspelt id.

→ The name in getElementById("send") must match id="send" in the HTML. node lint.js checks all of them.

The voice says "asterisk asterisk"

The model wrote Markdown and the speaker read the symbols.

→ Already stripped automatically. If you see it, check clean() in app.js.

It refuses everything

Temperature too high, or a persona that forbids things.

→ Press Reset to defaults.

Port 5001 is already in use

An old copy is still running.

→ Close the previous window, or restart the machine. start.py warns about this on launch.

9What it's bad at

Be honest about this, so nothing disappoints you later.

Good at
Short replies
Two or three sentences, in a voice you chose, under a second.
Bad at
Big sums
17 × 23 is about its limit. It'll get it right, then get it wrong.
Good at
Private data
Nothing you say ever leaves the machine.
Bad at
Today's news
Its knowledge stops at its training date.

The important one

It doesn't know when it's wrong. It will say something false with exactly the same confidence as something true. That isn't a bug you can patch — it's how this kind of model works.

10The one thing to remember

The AI is 628 MB of files sitting on your laptop.
Not a website. Not a company. Files.

ChatGPT's version lives in a warehouse of graphics cards. Yours lives in a folder. It's much less clever — and it's completely yours, costs nothing, and never tells anyone what you asked it.

That trade is the whole point.
